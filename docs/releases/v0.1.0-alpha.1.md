**Proposed notes; not published.** The first tag remains pending integration of these

This is an experimental, local-first source preview under [Apache-2.0](../../LICENSE).
It is not stable, an accepted functional Desktop MVP or a validated real-provider
team workflow. There are no packaged installers, signed/notarized distribution or
automatic updates in this preview.

## Included implementation

- Read-only discovery and incremental ingestion of external Codex JSONL sessions,
  deterministic source-backed events, checkpoints, replay/recovery and local SQLite
  storage. The default observer never sends input to external sessions.
- A UI-independent observation Core, loopback Bridge REST/WebSocket transport and
  shared React dashboard for workspaces, sessions, timeline, attention and tokens.
  Captured content stays in its original language and is rendered as inert text.
- English and Brazilian Portuguese UI, dark/light/system themes, reading preferences,
  workspace pins, search over loaded data and an optional observation guide.
- Model Usage Analytics with bounded worker queries, ranking/filtering, observed
  usage evolution, descriptive comparison and aggregate CSV/Markdown export. Missing
  attribution and coverage gaps remain explicit; cached input is a subset of input.
- Manual Artifacts from retained messages, bounded source-library browsing,
  memory-only draft editing/restore/discard guards and explicit Markdown save.
- An experimental macOS Electron checkout client, tray and native notification
  mechanism. Explicit native opt-ins provide owned A/B terminal panels, reviewed
  tool PATHs, native consent, conservative ownership and lifecycle boundaries.
  Existing external sessions stay observation-only.
- Experimental scoped communication, structured Codex and MCP transport libraries,
  with synthetic correlation/delegation evidence. Their presence does not establish
  real CLI compatibility or automatic results inside a provider CLI.
- Desktop startup tolerates closed stdout/stderr diagnostic writes (`EPIPE`, `write`)
  while retaining failure behavior for unrelated stream errors. Disposable Electron
  fixtures establish this mechanism; they do not prove the cause or process identity
  of the earlier historical error. See the [diagnostic-output evidence](../development/desktop.md).

## Known limitations

- Codex is the only implemented external-session observation adapter. Claude Code
  and OpenCode observation remain contracts; passive CLI discovery and terminal
  opt-ins do not promote them to validated observers or managed providers.
- Real-provider login/model/delegation and complete two-real-agent acceptance remain
  pending or blocked. The earlier authorized structured native attempt failed
  before readiness/task submission; synthetic A-to-B-to-A checks do not accept it.
  OpenCode startup has separate effects/migration consent and remains blocked unless
  its documented native review is explicitly completed.
- Native notification delivery under a signed app identity, manual native visual
  acceptance and the complete Desktop Analytics/MVP criteria remain unaccepted.
  macOS is the primary development target; other OS/browser support is not certified.
- Unknown ownership/outcomes retain reservations; inactivity does not prove task
  completion, process exit or safe retry. Durable reconnect and general N-member
  teams are not part of this baseline. Terminal layouts/drafts have documented
  memory-only limits; retained-source search is not a complete archive index.
- Analytics reflects observed usage, not provider billing, task quality, model
  entitlement, recommended models or a cost/success ranking. Real multi-model
  coverage and arbitrary-archive performance remain unvalidated.
- Redaction is best-effort. Captured content and model identifiers may be sensitive;
  inspect exports before sharing. Native file writes are not guaranteed atomic or
  crash-recoverable. No Cloud service or production Token Optimizer is included.

## Run and validate

Use the source checkout with Node `>=24 <25` and pnpm `10.34.9`, as declared in the
repository. Follow [Setup](../development/setup.md) and the existing
[Desktop guide](../development/desktop.md); a source archive is not an installed app.
Follow [local deployment](../deployment/local.md) for private data locations and
backup/upgrade considerations. Publishing a tag does not update existing services.

The [validation record](../../README.md#validation-status) and
[testing guide](../development/testing.md) distinguish historical automated,
synthetic, real-source and native evidence. They are not a fresh full-suite run on
an unreleased target. The release review must record actual checks against the
selected commit and retain every failed/skipped check and acceptance limitation.
