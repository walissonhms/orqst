## Method

For each remote branch outside the baseline's ancestry, `git cherry` was
compared with `git patch-id --stable` from non-merge diffs with rename detection
disabled. In the evidence column, `+N/-M` is the cherry count and `P` is the
number of stable patch matches in the baseline's history. Patch matches locate
original changes. Pickaxe searches (`git log -S` on the indicated symbols and
paths) and reads at the baseline establish whether the behavior survived later
changes. Commit subjects serve as leads to inspect diffs. The kernel tip is an
empty WIP commit, so Git counts 38 commit objects and the stable pass has 37
nonempty patches. Documentation and tests mentioned below are source evidence.

## Kernel reservation release and V6 scope

AGENTS.md §1 and §5 govern recovery. The November 5 decision permits releasing
an explicitly owned reservation across launches only with documented macOS
kernel identity, complete session checks, a durable producer fence and one
fresh native owner confirmation. The current `physicalDifference` release
contract and its Rust recovery port cover a separate administrative
cross-boot flow. The branch's kernel evidence, review and mutation-lock
coordinator still require reconciliation with the current Node and Rust
producer paths and separate native acceptance. Preserve legacy reservations
without eligible identity and every unknown, contradictory or inaccessible
case. A scoped absence decision preserves original evidence and supplies no
task completion, exit status, signal or exited receipt.

The four older V6 branches explain why branch ancestry alone gives the wrong
answer about the frontend. The baseline implements the Workspace/Feature
hierarchy, distinct pane controls, dock, Feature policy foundation and
renderer failure handling. The [current Workspace and Agentic audit](workspace-agentic-audit.md)
records other gaps, including full planning and dispatch, lifecycle-aware
archive of populated Features and owner native checks. The approved
[V6 sources](../design/v6/README.md) describe the intended product. Current
composition and source tests establish individual paths, with native visual
and provider acceptance tracked separately.
