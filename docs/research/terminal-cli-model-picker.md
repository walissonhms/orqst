## Existing ORQST reuse and modifications

Retained `discoverLocalClis` / `discoverTerminalExecutable` and exact binary pins,
`prepareTerminalCreation`, versioned Codex/Claude/OpenCode manifests,
`interactiveTerminalProfiles`, the existing broker/supervisor/admission, Core and
PTY backend. Added a database-owned read-only workspace lookup, trusted Core
workspace/Feature binding, opaque catalogue/model schemas, bounded passive source
reader and model evidence extensions to profiles. Existing legacy manifests omit
these optional extensions and retain their prior contract.

No new dependency, runtime/session manager, credential backend, automatic login,
provider execution or provider DB access is introduced. New tests use synthetic
source files and pin substitutions confined to test bundles; they never execute
the synthetic provider binaries. Native UI/provider acceptance and the complete
three-CLI dynamic model-catalogue acceptance remain open.
