# Terminal close reference review

The official V6 HTML models the pane, maximize, minimize, close and dock
controls. The preserved V6 specs give separate lifecycles to hiding,
detaching, stopping a task and terminating a process. The production code
uses ORQST's owned PTY, journal and native confirmation contracts.

| Reference          | Source and decision                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Anywh, Apache-2.0  | Inspected [architecture](https://github.com/anywh-sh/anywh/blob/546f189c04415c3c5af5f40e3931a0a90b9aba31/docs/architecture.md), [Agent Host docs](https://github.com/anywh-sh/anywh/blob/546f189c04415c3c5af5f40e3931a0a90b9aba31/docs/agent-host.md), [Agent Host lifecycle](https://github.com/anywh-sh/anywh/blob/546f189c04415c3c5af5f40e3931a0a90b9aba31/relay/src/agentHost/agentHost.ts), [terminalSession.ts](https://github.com/anywh-sh/anywh/blob/546f189c04415c3c5af5f40e3931a0a90b9aba31/relay/src/host/terminalSession.ts) and [LICENSE](https://github.com/anywh-sh/anywh/blob/546f189c04415c3c5af5f40e3931a0a90b9aba31/LICENSE). Use ORQST's existing owned-handle wait. Anywh's Node, node-pty and tmux paths support host removal, process sweeps and escalation. ORQST release instead depends on its source-backed signed exit and preserved journal. |
| Tucano, Apache-2.0 | Inspected [router.ts and LICENSE](https://github.com/eduwxyz/tucano/tree/0501956d127699300209902e889f3e69a0948766). The Node router's `routerPrompt` and `parseRoute` select a speaker. Keep ORQST's exact Feature-scoped membership and omit closed terminals from live routing.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| T3 Code, MIT       | Inspected [Terminal Manager](https://github.com/pingdotgg/t3code/blob/de7b5e05f6a95573f65c923727fe84542a5b86e9/apps/server/src/terminal/Manager.ts) and [LICENSE](https://github.com/pingdotgg/t3code/blob/de7b5e05f6a95573f65c923727fe84542a5b86e9/LICENSE). Its Effect/PtyAdapter session manager separates views and PTY lifecycle, with thread-scoped locks and persisted scrollback. Keep ORQST's signed native permission gates and SQLite/receipt authority instead of adding shared process machinery.                                                                                                                                                                                                                                                                                                                                                            |
| Overclock          | Reviewed the [public Panes feature](https://overclock.sh/features/panes) for pane discovery and visual controls. A public application source SHA and an applicable source/asset license were not established. Use the owner-approved V6 HTML for visual implementation.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |

The inspected source trees had root licenses. No third-party code, dependencies,
visual assets or notices were introduced.
